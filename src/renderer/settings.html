サーバー

内蔵サーバーの設定は、LibreChat の .env・librechat.yaml と同じ書き方で変更できます（再起動後に反映）。OpenAI・Claude・Gemini の API キーは、チャット画面のモデル選択にある歯車アイコンからも入力できます。

サーバーの切り替えは Lamplight の再起動後に反映されます。

拡張機能

必要な機能を拡張機能として追加できます（.lamplightext ファイル）。拡張機能はこのコンピューターの上で、あなたの権限でプログラムを実行します。信頼できる配布元のものだけを追加してください。

外部サーバーに接続しているあいだは、拡張機能は使えません（内蔵サーバーで動きます）。

変更はサーバーの再起動後に反映されます。

クイック入力

例: Alt+Space、CommandOrControl+Shift+Space。Mac では Alt が ⌥ キーです。

お気に入りモデル

クイック入力とメニューバーから選べるモデルです。エンドポイント名はモデル一覧の見出し（例: Ollama、openAI、anthropic）と同じにします。
